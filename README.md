## Featured Projects

### AURA

**Automated Unified Recognition-based Attendance**

An IoT-based attendance platform built using RFID, ESP32, NRF24L01 wireless communication, Python and Django.

```text
RFID / PN532
     │
     ▼
ESP32-S3
     │
     │ NRF24L01
     ▼
ESP32-WROOM
     │
     ▼
Python Serial Bridge
     │
     ▼
Django Backend
     │
     ▼
Attendance Management
```

**Core Components**

* ESP32-S3 + PN532 RFID reader
* ESP32-WROOM receiver
* NRF24L01 wireless communication
* Python serial bridge
* Django backend
* REST APIs
* Teacher session management
* Student attendance tracking
* Offline data handling
* Local backup and synchronization

**Focus:** IoT · Embedded Systems · Wireless Communication · Python · Django

---

### AirFence

**IoT-Based Wireless Threat Detection & Evil Twin Identification**

AirFence is a wireless security research platform designed to identify suspicious wireless infrastructure using ESP32-based scanning, Python processing, Django and machine learning.

**Capabilities**

* Wireless access-point discovery
* Rogue AP detection
* Evil Twin identification
* RSSI analysis
* Channel analysis
* Encryption classification
* Offline SD-card logging
* ESP32 edge monitoring
* Django security dashboard
* Machine-learning based classification
* Security reporting

**Technology**

`ESP32` `Python` `Django` `SQLite` `scikit-learn` `pandas`

**Research Publication**

> *AirFence: IoT-Based Wireless Threat Detection and Evil Twin Identification Using ESP32 and Machine Learning*

Published through IJIRT.
