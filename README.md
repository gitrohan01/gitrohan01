## 🧠 About Me

I am an offensive security researcher specializing in **web application penetration testing, web exploitation, and red team operations**. My work centers on enumerating attack surfaces, identifying vulnerabilities, and demonstrating realistic exploitation and privilege escalation paths across Linux and web environments.

I hold the **eJPT (eLearnSecurity Junior Penetration Tester)** certification, rank in the **top 1% globally on TryHackMe**, and was selected as an **Associate System Engineer at TCS through HackQuest Season 10**, a national-level CTF competition, after clearing multiple rounds of offensive security challenges.

My hands-on learning is built through CTFs, Boot2Root labs, and vulnerable web applications on TryHackMe and Hack The Box, where I consistently practice the full attack lifecycle — from reconnaissance to post-exploitation.
